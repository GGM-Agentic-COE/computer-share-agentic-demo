Cross-cutting components

Quality assurance layer

L1-quality-verifier — independent, rubric-based scoring

Takes the draft output of whichever agent just ran together with that gate's rubric, and returns a score out of ten, a pass/fail verdict and a rationale. It never re-fetches its own inputs, which is what makes it independent rather than a second opinion from the same evidence.

18 gates across the lifecycle, minimum 7/10 — except task-completeness, which passes at 6.

Reasoning patterns in play: Reflection on every agent · Verification on critical steps · Chain-of-thought on design and planning agents · Grounding everywhere · Citation on vision, story and test agents · Graph reasoning on the dependency mapper.

Guardrail chain

Applied to every agent output, in order

  1. gr-L1-output-schema-validatorReject if the output does not match its JSON schema
  2. gr-L1-pii-detectionBlock if real PII appears in output or in synthetic data
  3. gr-L1-hallucination-checkFlag ungrounded claims — entities, references, figures
  4. gr-L1-consistency-checkFlag contradictions within and across phase outputs
  5. gr-L1-citation-verifierEvery citable figure must carry a resolvable source
  6. gr-L2-domain-complianceValidate domain regulatory references are correct
  7. gr-L1-secret-scannerBlock hardcoded credentials in generated code
  8. gr-L1-license-compliance-checkFlag a disallowed OSS license in generated dependencies
  9. gr-L1-schema-validatorStructural validation of typed artifacts (OpenAPI, SQL, feature files)
  10. gr-L1-decomposition-rightsizingReject features and Work Units outside the right-size band

Layering

Every agent here is defined at L1 (Enterprise) — generic and reusable across any domain.

For a line of business, extend via instructions_append and knowledge_bases_append: L2-{domain}-vision-market-analyzer extends L1-vision-market-analyzer with domain framing.

For a project, L3-{project}-design-hld extends the L2 agent with ADRs and sprint baselines. Tools stay at L1 unless the system itself is domain-specific.

L2, L3 and L4 variants are created by extension, never duplicated into this blueprint.
